Employee Attrition Analysis

Project Overview

This project analyzes employee data using Microsoft Excel to identify patterns and factors associated with employee turnover. The analysis uses PivotTables, charts, and an interactive dashboard to transform raw employee data into meaningful business insights.

Objective

The objective of this project was to understand employee turnover and identify factors that may influence employee retention, including salary, promotion opportunities, workload, and employee satisfaction.

Tools Used

- Microsoft Excel
- PivotTables
- Data Cleaning
- Data Visualization
- Dashboard Development

Key Findings

- 23.8% overall turnover: 3,571 out of 14,999 employees left the organization.
- Salary: Low-salary employees recorded a 29.7% turnover rate, compared with 6.6% among high-salary employees.
- Promotion: Employees without promotion recorded 24.2% turnover, compared with 6.0% among employees who had been promoted.
- Workload: Employees with higher workloads showed higher turnover, suggesting that workload may influence employee retention.
- Employee satisfaction: Lower satisfaction levels were associated with higher employee turnover.

Recommendation

The organization should review compensation, improve workload balance, and provide clearer promotion and career-development opportunities. These measures could improve employee satisfaction and help reduce employee turnover.
