# Excel Sales Analysis

## Project Overview
This project focuses on cleaning, analyzing, and extracting insights from a sales dataset using Microsoft Excel.

## Data Cleaning
The following data-cleaning activities were performed:
- Removed duplicate records
- Corrected data formatting
- Filled missing information where appropriate
- Separated date and time
- Standardized data values

## Analysis
- Created PivotTables
- Analyzed revenue by country
- Analyzed revenue by product
- Identified top-performing countries and products

## Key Insights
The analysis identified patterns in revenue performance across countries and products and highlighted the areas contributing most to overall sales.

## Tools Used
- Microsoft Excel
- PivotTables
- Excel formulas

## Project Outcome
The project demonstrates the use of Excel for data cleaning, analysis, visualization, and business insight generation.
